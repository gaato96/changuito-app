00. Principios Visuales

Cálido, Claro y Confiable

✓ Voz vecina y de acá: Copete siempre en tuteo argentino («vos»), directo y transparente.
✓ Sin logos comerciales: Identidad neutral con punto de color (10px) y nombre en texto.
✓ El ahorro manda: Cifras grandes con números tabulares para no saltar entre góndolas.
